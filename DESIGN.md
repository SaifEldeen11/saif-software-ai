# Saif dark portfolio update

Reference: https://www.faisalnassef.com/ and the two screenshots supplied by Saif on 12 November 2026. Existing source: https://github.com/SaifEldeen11/saif-software-ai . This is an extension of the existing dark portfolio, not a new light design.

## Observed visual patterns

The supplied dark screenshot shows a near-black dotted background, charcoal cards with fine gray borders, rounded corners, peach accents, serif section headings, a three-link navigation with an underline for the current section, and a service column alongside a booking panel. The live capture defaulted to a light Arabic state; the supplied screenshot is authoritative for the requested dark treatment. Automated branding estimates for the default light state are not used as dark-theme tokens.

## Existing tokens retained

- Background #090a0d; foreground #f1f1f2; muted #b0b6c2; accent #edac94; panel #15171b; border #292d34.
- DM Sans for English body text, DM Serif Display for English display headings, IBM Plex Sans Arabic for Arabic, Aref Ruqaa for the Arabic name and selected headings.
- Existing fan of technology cards, illustrated automation demo, scroll-drawn arrows, and bilingual content.

## Changes

Home / Projects / About sticky navigation; real project cards and expandable Smart Hotel story; expanded About text; three service cards organized around what is built, why it matters, and the outcome; sticky booking panel with Saif's actual 30-minute Calendly link; visible 22px dotted grid and adjustable grid-only zoom from 60 to 180 percent. No portrait in the hero, invented testimonials, audit guarantees, or custom availability data.

The service/booking columns stack on small screens. Grid zoom changes background spacing, not content scale. Local storage remembers language and grid spacing; the site remains usable when storage is unavailable. Reduced-motion preference disables nonessential animation.
